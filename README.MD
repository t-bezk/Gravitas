##Introduction##

Project Gravitas is a simulation which is interested in a variety of orbital mechanics based systems. As well as using n-body solvers to make predictions from data, Gravitas aims to use more sophisticated techniques for the purpose of decreasing computational times required to locate trajectories.

##Version 1.0##

The original code was written in C++ and aimed to simulate n-body systems in 2 dimentions as well as plot their trajectories in real time.


##Version 3.0##

Gravitas Py 3.0 is the latest version and is written in Python to accelerate development in hopes of moving to a compiled language at a later time. A prokchop plot generator is currently in development with a time-step patched conic approximation simulator. 

Use ephemeris_plot.py to get porkchop plots
